# Project Wiki — Multi-Source Collector

The collector has a Java 27 CLI and a local authenticated REST service. It supports Google News search RSS, user-provided Google Alerts RSS where available, and public WordPress RSS/Atom. Reddit support was canceled by the owner and removed. Issuu public discovery is unavailable, so that source remains disabled.

The private capability matrix and source evidence live in the canonical project context. This repository's README documents the public setup and runtime behavior.
